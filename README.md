Estilo Vivo - Sistema de Gestión ERP

Aplicación web desarrollada para la gestión integral de la tienda "Estilo Vivo", especializada en artículos para el hogar. Este sistema busca solucionar problemas de desorden financiero y falta de control de inventario mediante una interfaz centralizada.

🚀 Despliegue en Vivo

Esta aplicación está diseñada para ser desplegada directamente en Vercel como un sitio estático.

🛠 Características Técnicas

Single File Application: Todo el código reside en un único archivo index.html para portabilidad máxima.

Tecnologías: React 18 (vía CDN), Tailwind CSS (vía CDN), Babel Standalone.

Persistencia: Los datos son volátiles (se reinician al recargar) para fines de demostración.

Interoperabilidad: El módulo de inventario alimenta automáticamente las proyecciones financieras y tributarias.
